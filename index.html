Empirical Software Engineering Research

Static Code Quality Analysis of Human-Written vs AI-Rewritten Java Code

Conducted a large-scale empirical study comparing the static code quality of human-written Java programs and their GPT-4o-rewritten counterparts. The research investigates code smells, coding-practice violations, and maintainability-related issues.

Research Methodology

  • Analyzed the GPT-Java-GCJ-Dataset using PMD 7.28.0 for static code quality assessment.
  • Developed a Python-based automated pipeline for file matching, batch processing, violation detection, and Excel reporting.
  • Performed paired comparisons using PMD violations, source code size, and normalized violation density.

Key Results

  • 76,088 Java files analyzed: 58,523 human-written and 17,565 AI-rewritten.
  • 17,059 matched pairs identified, with 17,043 valid pairs retained after validation.
  • Achieved 99.91% pair retention after excluding incomplete analyses.
  • Generated comparative code quality reports to support analysis of improvements and regressions introduced by AI rewriting.

Research Contribution

Developed a reproducible framework for large-scale static code quality analysis and established a validated paired dataset for comparing human and AI-rewritten code. Further statistical evaluation is ongoing.
